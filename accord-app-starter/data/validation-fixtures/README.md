# Validation Fixtures

Only synthetic or fully de-identified fixtures belong in this directory. These fixtures may be committed to Git after confirming that they do not expose or unnecessarily resemble actual client identities.

Fixtures should exercise:

- form selection;
- field mapping;
- checkbox and radio selection;
- addendum wording;
- package grouping;
- source links; and
- duplicate-transaction prevention.

Real, partially redacted, or otherwise confidential transaction examples belong under `../../private-data/`, which is local-only and ignored by Git.
